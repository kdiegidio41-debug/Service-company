              Your data

              Everything Jarvis reports comes from here. It starts empty and it stays empty until you put something in it — nothing is estimated or filled in for you. It saves to this browser only.

              Product

              Standing figures

              Totals that aren't a daily number. Set them once, update when they move.

              Log a day

              Pick a date and enter what happened. Use this to backfill history; day to day it's faster to just say “log 250 revenue”.

              Voice

              Live feed not connected

              Point Jarvis at the metrics proxy in server/ and it pulls revenue, downloads and views on its own. Sources the proxy can't answer for stay on whatever you logged by hand, and your flags and handled items always stay local.

              Agents

              Watchers run here, over your own logged numbers. No key, no network, no cost — they run every time you open Jarvis. Each one clears its own findings when they stop being true. Say “run the agents” to sweep on demand.

                Thinking agents call Claude through the proxy and cost money per run, so nothing triggers them but you. Set ANTHROPIC_API_KEY on the proxy, then ask for a strategy, hooks, or a script.

                Backup

                This data lives in one browser. Copy it out before you clear site data or switch machines.

                What you can say

                Say “hey Jarvis” then the command, or press space to skip the wake word. Every command below also works typed, so Jarvis is fully usable with no microphone. All figures start at zero — they only move when you log something.

                Logging — how data gets in

                • Log 250 revenue
                • Log 40 downloads
                • Log 12k views on TikTok
                • Set MRR to 890
                • Set followers to 1,200
                • Set active users / conversion / churn
                • Published … on YouTube with 8000 views

                Your open items

                • Flag … — adds to Needs you
                • Handled … — logs it as done
                • Resolved … — clears a flag
                • What needs me
                • What did you handle

                Reading it back

                • Brief me — everything, in order
                • How's the app doing
                • What's the revenue
                • How are downloads
                • How did content do
                • How's TikTok doing
                • What was the top post

                Content ops

                • Queue a post about …
                • Schedule a TikTok about … tomorrow
                • What's in the queue
                • Mark … as posted
                • Give me hooks about …
                • Write a script about …

                Memory

                • Remember …
                • Remind me to …
                • What are my ideas
                • Settings — opens the data panel

                Keys

                • space — talk without the wake word
                • / — focus the command line
                • B — briefing
                • D — your data
                • M — mic on / off
                • esc — stop

                If the mic won't work

                • Recognition needs https or localhost. It will not run from a file:// page or inside an embedded frame.
                • Install Jarvis as an app, or serve it with python3 -m http.server, and the wake word works.
                • Chrome, Edge, Brave or Arc only. Safari and Firefox have no recognition — everything still works typed.
