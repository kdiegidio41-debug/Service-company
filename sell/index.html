Making your own takes one file

No plugin system, no SDK to learn. Drop a .agent.json into the agents/ folder and it shows up in the CLI and the dashboard.

{
  "id": "restock-watcher",
  "name": "Restock Watcher",
  "schedule": { "dailyAt": "10:00" },
  "inputs": [{ "key": "stock", "label": "Current stock", "required": true }],
  "prompt": "From this stock list: {{stock}} — what runs out first for
             {{business.name}}, and what to reorder today."
}

Before you buy

The things that stop people, stated up front.

Do I need to be technical?

You need to be able to open a terminal and run three commands. If that sentence worries you, buy the done-for-you tier and we'll install it — don't buy the self-serve tier and hope.

What does it cost to run?

You pay Anthropic directly for API usage on your own key. A typical agent run costs cents. An operation with four scheduled agents usually lands around [SET: $5–40]/month. The dashboard totals your actual spend so there are no surprises, and --dry-run lets you test anything for free.

Does it run when my computer is off?

No. Scheduled agents run while the machine is awake and the scheduler is running. If you want it running 24/7, put it on a cheap always-on box — or ask about [SET: hosted option].

Is the output good enough to send to a customer?

Read it first. Every agent is written to refuse to invent facts, prices, and quotes — it marks gaps [NEEDS: ...] instead — but it is language-model output and it can be wrong. Treat it as a strong first draft that saves you the blank page, not as something to forward unread.

Will this make me money?

No honest answer here is a number. It saves time on work you're already doing and gets drafts written that otherwise sit undone. What that's worth depends entirely on your business. Anyone selling you AI agents with a revenue figure attached is guessing.

Can I resell it or use it for clients?

Using it to deliver work for your clients is fine and encouraged. Redistributing the software itself needs a reseller license — ask at [SET: email].
