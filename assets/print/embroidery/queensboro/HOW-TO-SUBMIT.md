# Submitting to Queensboro

Two files in this folder. Everything else in `assets/print/embroidery/` is for a human
to read — Queensboro's uploader only wants artwork.

| File | Upload as | Size |
| --- | --- | --- |
| `EVERGLOW-front-logo.png` | Front / left chest | 10.5 × 3.7in @ 300dpi |
| `EVERGLOW-back-logo.png` | Full back | 11 × 9.3in @ 300dpi |

Both are transparent PNG, 300dpi, well under their 15MB cap. Queensboro accepts
.AI, .PSD, .EPS, .PNG, .JPEG and .PDF and asks for 300dpi on a transparent background,
so these are exactly to spec.

---

## The garment

**Carhartt Embroidered Men's Midweight Crewneck Sweatshirt — Queensboro style 7107.**
This is the K124 we specced, and Queensboro stocks it, so no substitution is needed.
Order it in **black**. Qty 5.

If you want to spend less, their Gildan Heavy Blend crewneck (style 7380) and Port &
Company Core Fleece (7780) are around $21–25 against the Carhartt's higher price. The
Carhartt is still the pick — the label itself is doing work when a homeowner sizes up
your crew.

---

## ⚠ The preview will look broken. It isn't.

**The wordmark is white, so against Queensboro's white uploader background it will look
invisible or nearly gone.** That is correct — the garment is black, so the thread has
to be white. Do not "fix" it by darkening the artwork.

Two things to do about it:
1. Set the **garment colour to black first**, before you judge the logo preview.
2. When you place the order, add a note: *"Artwork is for a black garment — wordmark
   stitches in white, not dark."*

---

## Names

Each sweatshirt was designed to carry the wearer's first name on the **right** chest,
opposite the logo. The front logo file here has the wordmark **centred** instead,
because an uploaded logo has to balance on its own.

If Queensboro's product page offers name personalisation, add it as a right-chest name
and you get the design as drawn. If it doesn't, you have two options: order the
sweatshirts plain from Queensboro and have a local shop add names later, or skip the
names — the garment still works without them.

---

## Before you approve

Queensboro digitises the logo free and sends a **proof**. Check three things on it:

1. **The bulb.** It has a gradient, and thread cannot do gradients. The digitiser will
   approximate it with 2–3 amber tones. Make sure it still reads as a lit bulb and not a
   flat orange circle.
2. **The light string.** Five bulbs, left to right: red, amber, green, blue, warm white.
   Make sure none were dropped or recoloured to simplify the stitch count.
3. **The small text.** `CHRISTMAS LIGHT INSTALLATION` is the smallest element on the
   garment. If it looks crowded on the proof, ask them to open the letter spacing rather
   than shrink it.

Approve the proof in writing before they run all five.
