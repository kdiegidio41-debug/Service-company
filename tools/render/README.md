# Mock-up renders

Every image in `assets/img/renders/` is generated by this folder. Nothing is a photo:
the house, the trees, the storefronts and the lights are all built in code with three.js
and rendered in headless Chromium. The random seed is fixed, so `before` and `after`
line up pixel for pixel — that is what makes the before/after slider work.

```bash
cd tools/render
npm install
npm run render                 # before + after → ../../assets/img/renders
node render.mjs out hero after # other frames (hero, service-*, og) into ./out
```

Chromium is found at `/opt/pw-browsers/chromium` by default; set `CHROMIUM_PATH` to use
another one. Each frame takes 5–30 seconds on a CPU renderer.

Handy knobs in `scene.js`:

| What | Where |
| --- | --- |
| Bulb color / brightness | `WARM`, and the `buildBulbs(...)` calls near the end |
| Glow amount | `UnrealBloomPass(..., strength, radius, threshold)` |
| Camera angles | the `views` table |
| Image sizes | the `JOBS` table in `render.mjs` |

These are illustrations. Replace them with real before/after photos of your own installs
as soon as you have them — see the main README.
